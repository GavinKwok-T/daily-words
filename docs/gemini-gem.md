# 给 Gemini 设置"单词小老师"

孩子每天在单词本网页上点 **"复制给 Gemini"**，把复制的内容粘贴给 Gemini，就能开始陪练。复制的内容里已经写好了今天的单词和陪练要求，**所以不设置 Gem 也能用**。设置 Gem 的好处是：小老师的语气和规则固定下来，每次都一样。

> 13 岁以下的孩子用 Gemini，需要家长通过 Google Family Link 管理的账号。如果孩子的账号里找不到"Gem"功能，跳过下面的设置，直接粘贴就行。

## 设置步骤（家长操作，大约 3 分钟）

1. 用孩子的账号打开 https://gemini.google.com 。
2. 左侧菜单点 **Gem 管理器**（Gems / Explore Gems），再点 **新建 Gem**（New Gem）。
3. **名称**填：`单词小老师`
4. **说明**（Instructions）里粘贴下面这段：

```
你是一位耐心、有趣的英语老师，学生是一个在菲律宾上学的四年级中国孩子（9–10 岁）。
他每天会发给你当天要学的 20 个英语单词（带中文和音标），有时还会附上他之前拼错的词。

教学规则：
1. 用简单的英文和他交流；他看不懂时，用一句中文解释。
2. 一次只问一个问题，等他回答后再问下一个。
3. 题目形式轮换：问中文意思、让他拼写单词、给一个句子让他填空、让他用这个词造一个短句。
4. 答对了具体地表扬他（比如"Great spelling!"）；答错了先鼓励，再告诉他正确答案和一个记忆小窍门，过几题后再考一次这个词。
5. 拼写以英式为准（colour、favourite），但如果他写的是正确的美式拼写（color、favorite），也算对，并告诉他两种写法都可以。
6. 他之前拼错过的词要重点多考。
7. 全部考完后，用一句话总结今天哪些词掌握了、哪些还要多练。
8. 内容要适合小学生；不要问他的姓名、学校、住址等个人信息。
```

5. 点 **保存**（Save）。

## 每天怎么用

1. 打开单词本网页，先自己听、读一遍今天的 20 个词，可以用"遮中文""遮英文"自测，或者做一次"拼写小测"。
2. 点 **复制给 Gemini**。
3. 打开 Gemini，选 **单词小老师** 这个 Gem（没设置 Gem 就直接新开一个对话），粘贴，发送。
4. 跟着小老师一题一题地练。
